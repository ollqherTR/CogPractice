# React Frontend Bank App

A simple React frontend built with Vite, React Router DOM, and Axios.

## Features

- React functional components
- React Router DOM navigation
- Axios API service layer
- Responsive customer table on Services page
- Simple CSS styling

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Open the app at `http://localhost:5173`

## API base URL

This app expects the backend API at `http://localhost:3000/api/v1`.
